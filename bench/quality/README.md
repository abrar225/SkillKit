# Paired artifact trial

The 15 prompts and automated checks were fixed in phase 1. Both arms use GPT-6.2 Sol at medium effort. Each arm receives the same ordered briefs in a separate fresh desktop agent session. The treatment also receives the exact text from the local handoff command. Outputs are saved as data. A session handles all briefs for its arm, so the 15 observations are correlated. No agent receives the opposing arm. These are short artifact tasks, not whole projects.

1. Run `python3 -B bench/quality/session.py prepare baseline /tmp/arm-one` and repeat with `with /tmp/arm-two`.
2. In two fresh same-model sessions, ask each to answer each prompt separately using only the packet and save sibling .answer files. Collect with `session.py collect <arm> <directory>`. Where the model is available to the CLI, `run.py baseline` and `run.py with` can alternatively run one ephemeral session per prompt. Label which protocol was used.
3. Run `python3 -B bench/quality/run.py blind` into a neutral file and give that file alone to a fresh judge. The deterministic A/B shuffle is fixed before outputs. For CSS, HTML, SVG and copy, score each side 0–2 for task fidelity, observable usability/legibility, and specificity/craft; 0 misses, 1 partial, 2 fulfills. Justify each decision briefly against the brief. Record per-side scores and explanations as an array of objects with id, A, B and reason. Keep ties. The judge sees source text, not rendered graphics. It must not inspect arm keys, other data or generation prompts.
4. Run `python3 -B bench/quality/run.py score` for automated results and `python3 -B bench/quality/results.py` for the combined table. Automated scores decide first; a tied automated score uses the blinded rubric when applicable. The denominator for the majority criterion is all 15 tasks. No attempt is made to infer universal or platform-wide accuracy.
