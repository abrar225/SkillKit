# Wikipedia Manual of Style: The Human Writing Blueprint

English Wikipedia contains over 6 million articles curated by millions of human editors over two decades. The guidelines that evolved from this collaborative effort represent the gold standard for clear, authoritative, neutral human prose.

---

## 1. Wikipedia:Plain English (WP:PLAINEX)

Human communication values clarity over ornamentation. Academic and AI writing frequently uses inflated vocabulary to mask thin ideas. Wikipedia's plain English standard requires direct, simple language.

### Conversion Table: Inflated vs. Plain

| Inflated / AI Word | Plain Human Replacement |
| :--- | :--- |
| utilize / leverage | use |
| facilitate | help, allow |
| methodology | method |
| commence / initiate | start, begin |
| terminate | end, stop |
| elucidate / demystify | explain, clarify |
| in close proximity to | near |
| a significant portion of | much of, most of |
| subsequent to | after |
| prior to | before |
| due to the fact that | because |
| in the event that | if |
| with regard to | about, for |
| optimal | best |

## 2. Words to Watch (WP:WORDS)

### A. Peacock Terms (WP:PEACOCK)
Peacock terms boast about a subject without giving verifiable evidence. 

* **Forbidden:** `legendary`, `groundbreaking`, `visionary`, `world-class`, `masterpiece`, `spectacular`, `breathtaking`, `revolutionary`.
* **Rule:** If the achievement is real, the facts will prove it. State the benchmark, the throughput, the parameter count, or the operational result. Let the reader decide if it is impressive.

### B. Weasel Words (WP:WEASEL)
Weasel words disguise opinion as common consensus.

* **Forbidden:** `some argue`, `critics state`, `many believe`, `it has been observed`, `widely considered`.
* **Rule:** Name the exact entity or author. If the claim cannot be attributed to a specific paper, commit, or benchmark, remove the claim.

### C. Editorializing Words
Words that tell the reader how to feel about a fact.

* **Forbidden:** `interestingly`, `remarkably`, `surprisingly`, `amazingly`, `naturally`, `of course`.
* **Rule:** State the fact directly. If an event is unusual, the contrast between expectations and reality will make that clear without editorial hand-holding.

## 3. Active Voice vs. Passive Voice (WP:ACTIVE)

AI models default to passive voice because it allows them to generate text without committing to an agent or subject:
* *Passive (AI):* `The memory cache was evicted as a consequence of latency degradation.`
* *Active (Human):* `The engine evicted the cache when latency crossed 200 milliseconds.`

Active voice forces clarity: **Who did what to what, and why?**
